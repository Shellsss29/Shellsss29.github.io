Why Apple Photos Thinks You're 5 Different People (And How to Fix It)

A simple AI problem Apple still hasn't solved—and a potential solution from facial recognition research

Shailly Bhati Software Engineer | AI/ML Enthusiast

The Problem

You open Apple Photos, go to the "People" album, and see yourself split into 5 different people. Same face, different clusters. You manually merge them, but next week? Split again.

This happens to millions of iPhone users. Apple's facial recognition creates duplicate "people" for the same person, and it's frustrating.

Why Does This Happen?

Apple Photos uses facial recognition AI to automatically group photos by face. When you take photos, it:

  1. Detects faces in each photo
  2. Creates a mathematical "face signature" (embedding vector)
  3. Clusters similar signatures together
  4. Each cluster becomes a "person"

The problem: The AI creates separate clusters for the same person when:

  • Lighting changes (bright outdoor vs. dim indoor)
  • Age differences (photos from 5 years ago vs. today)
  • Angles (front-facing vs. side profile)
  • Accessories (glasses on/off, hats, makeup)
  • Photo quality (blurry vs. sharp)

The clustering algorithm thinks "These faces are too different—must be different people."

Why Apple Hasn't Solved It

Apple faces a tough tradeoff:

Make clustering too strict → Same person split into multiple clusters (current problem)
Make clustering too loose → Different people get grouped together (worse problem)

Apple chooses the conservative approach: better to split one person than merge two different people. But it's still annoying.

The Solution: Context-Aware Face Recognition

Here's how we can solve this using techniques from computer vision research:

1. Use Multiple Signals Beyond Just the Face

Don't rely only on facial features. Consider:

  • Clothing patterns: Same person often wears similar styles/colors
  • Location metadata: Photos taken at the same place likely have the same people
  • Time clustering: Photos taken together (within hours/days) likely have the same people
  • Body shape and posture: Supplement face data with body recognition

2. Hierarchical Clustering Instead of Flat Clustering

Instead of creating one big cluster per person, use a two-level approach:

  • Level 1: Create micro-clusters (very similar faces)
  • Level 2: Link micro-clusters that likely belong to the same person using context signals

This way, your face with glasses and without glasses are separate micro-clusters but linked as the same person.

3. Adaptive Similarity Thresholds

Use different similarity thresholds based on:

  • Photo quality (allow more variation for blurry photos)
  • Time span (allow more variation for photos years apart)
  • Number of matching context signals (lower threshold if location/clothing match)

My Experience with Facial Recognition

During my master's at Northeastern University, I worked on an Image Spoof Detection project focused on facial recognition challenges. We built systems to:

  • Detect subtle facial features across different conditions (lighting, angles, quality)
  • Distinguish real faces from fake presentations using texture and depth analysis
  • Handle facial variation while maintaining security
Key insight: Facial recognition isn't just about matching faces—it's about understanding context. The same techniques used to detect spoofing (analyzing texture, depth, consistency) can improve clustering accuracy.

In spoof detection, we learned that:

  • Texture analysis helps differentiate faces under different lighting
  • Multi-modal signals (RGB + depth + context) are more reliable than single features
  • Temporal consistency (how faces appear over time) catches what single-frame analysis misses

These same principles apply to solving Apple's clustering problem.

How to Fix It Yourself (For Now)

Until Apple improves their algorithm, here's what you can do:

Manual Merge:

  1. Open Photos app → People album
  2. Tap "Select" in top right
  3. Select all duplicates of the same person
  4. Tap "Merge" at the bottom

Name Them:

Add names to your "people" - this helps the AI learn and reduces re-splitting

Keep Original Photos:

Avoid heavy filters/edits that change facial features significantly

What Apple Should Do

Short-term fix:

  • Add a "confidence score" showing how sure the AI is about each cluster
  • Let users mark clusters as "same person" and learn from it

Long-term solution:

  • Implement multi-signal clustering (face + context)
  • Use on-device learning to adapt to each user's photo library
  • Leverage depth data from iPhone cameras (already available, not fully used)

The Bottom Line

Apple Photos splitting the same person into multiple clusters is a clustering algorithm limitation, not a fundamental AI failure. The fix exists—it just requires:

  1. Better context awareness beyond facial features
  2. Hierarchical clustering instead of flat clustering
  3. Adaptive thresholds based on photo quality and metadata

With techniques from facial recognition research (like those used in spoof detection), this problem is solvable. Apple just needs to implement it.

Until then, keep manually merging those duplicates.
